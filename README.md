# 📋 나만의 프롬프트 관리 프로그램

터미널에서 동작하는 **콘솔 기반 프롬프트 관리 프로그램**입니다.
GenAI 미션을 수행하며 쌓인 프롬프트를 체계적으로 저장·검색·관리할 수 있습니다.

## 📌 프로그램 소개

흩어져 있던 프롬프트를 한곳에서 관리하기 위해 만든 프로그램입니다.
카테고리별 분류, 키워드 검색, 즐겨찾기 기능을 제공합니다.

## 🚀 실행 방법

```bash
# 1. 저장소 복제
git clone https://github.com/cherry5525/A1-1

# 2. 폴더 이동
cd A1-1

# 3. 실행 (Python 3.10 이상)
python main.py
```

## 🛠️ 기능 목록

| 번호 | 기능 | 설명 |
|------|------|------|
| 1 | 프롬프트 추가 | 제목·내용·카테고리 입력하여 등록 |
| 2 | 프롬프트 목록 | 전체 프롬프트를 번호와 함께 출력 |
| 3 | 카테고리별 조회 | 선택한 카테고리의 프롬프트만 출력 |
| 4 | 프롬프트 검색 | 제목·내용에서 키워드 검색 |
| 5 | 프롬프트 상세 보기 | 프롬프트 전체 내용 확인 |
| 6 | 즐겨찾기 관리 | 즐겨찾기 추가/해제 |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아보기 |
| 0 | 종료 | 프로그램 종료 |

## 🗂️ 프롬프트 카테고리

- **텍스트 생성**: 글쓰기, 요약 등 텍스트 관련
- **이미지 생성**: 이미지 생성용 키워드/지시문
- **영상 생성**: 영상 스크립트, 콘텐츠 기획
- **페르소나**: AI 역할·성격 설계
- **자동화**: 반복 작업 자동화용 프롬프트
- **기타**: 그 외 분류

## 💾 데이터 구조

프롬프트는 **리스트 + 딕셔너리**로 저장됩니다.

```python
prompts = [
    {
        "title": "블로그 글 작성 도우미",
        "content": "당신은 10년 경력의 전문 블로거입니다...",
        "category": "텍스트 생성",
        "favorite": True
    }
]
```

> ⚠️ 데이터는 프로그램 실행 중에만 유지되며, 종료 시 초기화됩니다.
